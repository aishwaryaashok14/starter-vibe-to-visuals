# Vibe to Visuals starter

A 90-minute build-along workshop in which students turn a physical-product store, software app, or service idea into a coherent interactive experience, social image, and short video.

## Core workflow

1. Choose a physical store, software app, or service route.
2. Answer three guided questions and create `STORE-KIT.md` or `DESIGN.md`.
3. Physical-product students generate one product-family reference and build the store in ChatGPT Sites.
4. App and service students import `DESIGN.md` into Google Stitch, build the focused journey, and select three strong visual moments from the finished prototype.
5. Create one 1080 × 1350 social image.
6. Create one silent 6–8 second video with three visible beats.
7. Compare every artifact with its source kit and visual reference, then repair one mismatch.

## Start here

- Open `index.html` for the student follow-along guide.
- Paste `PROJECT-INSTRUCTIONS.md` into a ChatGPT Project's instructions.
- Choose the build route at the top of the guide. The page swaps in the relevant questions, prompts, checkpoints, and submission list.
- Add the relevant template, source file, and visual references to the Project as the workshop progresses.
- Physical-product route: use ChatGPT Sites for the store and publish publicly when workshop sharing is allowed.
- Software and service routes: use Google Stitch for the core journey. A shareable prototype link or saved export is sufficient.

## Recovery routes

- `fallback/` contains the Soft Hours Store Kit and product reference.
- `website-starter/` is the physical-store recovery build if Sites is unavailable.
- For an app or service, ChatGPT Sites is the recovery route if Stitch is unavailable after two minutes.
- `video-template/` provides the no-generation browser-loop fallback.
- The student guide applies a two-minute switch rule when an optional tool or account is unavailable.

## Optional tool lanes

- Pomelli can create campaign concepts from a publicly accessible Site URL.
- Google Flow can create the short video from the selected visual and social references.
- Adobe Express or CapCut can assemble the same required outputs without relying on live generation.

These tools do not change the evidence gate. Students submit their source file, visual reference, store or Stitch prototype, social image, video or animatic, and consistency check.

## Instructor materials

- `FACILITATOR-RUN-OF-SHOW.md` contains the timed workshop plan and intervention rules.
- `TEST-RUN-REPORT.md` records the validation and remaining live risks.
- `instructor/Vibe-to-Visuals-Sites-First-v11.pptx` is the final workshop deck.

## Codex route

The repository retains the `$vibe-to-store` skill under `.agents/skills/vibe-to-store` for the physical-product route. The combined Project instructions and student guide also support software apps and service experiences.
